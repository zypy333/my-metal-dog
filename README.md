# 撸铁雷达 · 我的健身房（非官方）

查看常去健身房实时人流与温湿度的非官方客户端，附带训练打卡日历。

> **本项目是个人兴趣作品，与「金属狗」App 及其运营方没有任何关联，未获授权，也未获其背书。**

## 功能

- **门店实时状态**：按省/市挑选常去的门店，集中展示这些门店的实时在馆人数与温湿度，支持下拉或手动刷新。
- **训练打卡日历**：按训练部位（胸、肩、背、腿、手臂、上肢、下肢、有氧）记录每日训练，日历页可回溯历史打卡。
- **多端运行**：同一套代码支持 Web（可安装为 PWA）、Android 与 iOS。
- **本地存储**：选中的门店和打卡记录仅保存在设备本地，不上传服务器。

## 技术栈

- Expo SDK 58 / React Native 0.88
- Expo Router（文件路由）
- AsyncStorage（本地持久化）

## 开发

```bash
npm install
npx expo start        # 启动开发服务器
npx expo start --web  # 在浏览器中运行
npx tsc --noEmit      # 类型检查
npx expo lint         # 代码检查
```

构建可安装的 PWA 产物：

```bash
npm run build:web     # 输出到 dist/，并注入 manifest、Service Worker 与图标
```
